# UI and motion

For UI work, follow `GUI.md` and the `graphical-ui` skill. This guide covers how the starter wires components, tokens, fonts, and motion.

- **Check `src/components/ui/` before you build a component.** Add a missing one with `npx shadcn@latest add <component>`. It writes the registry's style, so convert what lint reports before you use the file: `cn` from `@/lib/utils`, `Icon`, the theme's sizes, and `ring` or a divider for each edge.
- **Actions are `Button`, navigation is `<Link>`.** To make a link look like a button, style it with `buttonVariants({ variant, size })`, so assistive technology still announces a link.
- **Icons come from `@hugeicons/core-free-icons`**, drawn with `Icon` from `@/components/icon`. Give an icon-only button an accessible name.
- **Use the theme's names.** `src/styles/app.css` defines the Untitled tokens, each color a `light-dark()` pair. An inline script from `src/lib/theme.ts` sets `.dark` on `<html>` before the first paint. Write `text-m`, `p-m`, `gap-s`, `rounded-s`, `font-heavy`, `bg-primary`, and `text-muted-foreground`. Tailwind's default type, radius, shadow, weight, and palette scales are gone, so `text-sm` or `bg-emerald-500` fails lint. `vp dev` and `vp build` regenerate `src/lib/cn-tables.ts` when the classes change. Commit it with your change.
- **Pass a dynamic value through a CSS custom property.** Set it in `style` and read it from a class, as in `<div className="w-(--progress)" style={{ "--progress": percent }} />`. Lint rejects any other inline style.
- **Draw edges with `ring` or `inset-ring`**, and dividers with `divider-t`, `divider-b`, or `divider-r`, not `border`. The theme draws every edge as a box shadow.
- **Fonts are cut to what the pages use.** `npm run fonts` builds the site, audits the sitemap and the pages `scripts/fonts/config.json` lists in Chromium, and cuts each face the config lists to the characters, weights, and OpenType features it finds. Each family also keeps every character in its `contentFiles`, for text the audit can't reach by visiting pages, such as data or user input. Commit the outputs `scripts/lib/project.mjs` declares. Each face gets a preloaded core file with ASCII and every character the pages use, plus an extended file behind `unicode-range` with a wider Latin set. Rerun it when a page adds a character outside ASCII, a weight or style that a variable face doesn't use yet, a `font-feature-settings`, `font-variant-*`, or `font-variation-settings` value, a `lang`, or `hyphens: auto`. Until you do, that text loads the extended file and loses kerning against its neighbours, or falls back to a system font. The script needs [uv](https://docs.astral.sh/uv/) and `npm run test:e2e:install`. The sources are the full upstream fonts, so text in another script they cover, such as Cyrillic, needs only a rerun. Never link a third-party font stylesheet.
- **Keep motion on the compositor.** Chrome runs `transform` and `opacity` animations off the main thread. Animated `filter`, `clip-path`, `width`, and `background-position` repaint on the main thread every frame, so keep them short. For keyframed or spring motion, call `element.animate()`, or `useWebAnimation` for precomputed keyframes. Motion's `spring` turns a spring into a CSS `linear()` easing.
- **Render the settled state on the server.** Content that animates in should render visible, and hide only after it mounts below the fold, so it shows without JavaScript. `usePlayOnView` works this way and handles reduced motion itself.
- **Time motion with the theme.** Use `duration-(--motion-duration) ease-(--motion-easing)` for controls, and the large curve for reveals and panels. Animate `transform` and `opacity`, never `transition: all`. Respect reduced motion with `usePrefersReducedMotion`.
- **Morph text that changes in place with `TextMorph` from `torph/react`.** Use it for a short label, count, price, or status that updates while the user watches, such as "Copy" to "Copied" or `$1,204` to `$1,318`. Letters the two values share stay put, and digits roll by place value. Pass text only, and keep it to one short line, because it resizes its element to fit. Don't wrap a paragraph, text that never changes, or an entrance animation in it. For a value the user types, pass `cursorIndex`. It follows reduced motion on its own.
- **Show loading with `Skeleton` from `skullet/react`.** Wrap the real component and pass the `data`, a `sample` of the same shape, and a `label` for screen readers: `<Skeleton data={user} sample={sampleUser} label="Loading profile">{(user) => <Card user={user} />}</Skeleton>`. Skullet lays the component out unseen and draws a bar for each line of text and a block for each image, so nothing moves when the data arrives. A loader that awaits its data needs no skeleton, because the page arrives complete. For a promise the loader returns without awaiting, wrap the component that calls `use()` in `SkeletonSuspense`. After `router.invalidate()`, the loader returns a new promise and the skeleton shows again. Pass the promise through `useDeferredValue` to keep the old content until the new data arrives. A load under 150ms shows no skeleton, so don't add a delay of your own. Give every image a `width` and `height`, and draw what can't be measured, such as a chart, with `SkeletonBox`. The `--skullet-*` tokens in `app.css` set the colors. Don't build a skeleton by hand or add shadcn's `Skeleton`.
- **Mark a milestone with a `glimm` sweep.** A WebGL band of color crosses the screen and the new view appears behind it. Use it when the user finishes something, such as publishing, submitting, or paying, or when the app enters a focused mode. Don't use it for ordinary navigation, hover or focus, repeated actions, or loading, because a sweep on every click stops meaning anything. Import from `glimm/react`, never `glimm/next`. Mount `GlimmProvider` in the layout route that owns those pages, not the root, because it adds about 17 KB gzipped to every route under it. Then call `sweep(() => navigate({ to, viewTransition: false }))` from `useGlimm()`. Without `viewTransition: false`, the router's own view transition blanks the page during the sweep. For a change inside one card or section, wrap it in `GlimmScope` and call `play({ change })`. A scope takes `style` but no `className`, so size it from its parent with `*:h-full`. Lower `brightness` to about `0.85` in dark mode. It skips the sweep under reduced motion.
- **Keep input text at least `16px`**, or iOS zooms in on focus. Use `tabular-nums` for numbers that change.
